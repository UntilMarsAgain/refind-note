# 首页

::banner color=#5b8dd6
  重逢笔记：笔记与它的全部历史，都存在你自己的机器上

## 从哪儿开始

- **写一篇**：在地址栏或新标签页输入一个还没有的名字，点「创建此笔记」，再点右上角「编辑」；
- **提交**：编辑器里点「提交」；提交前的内容会自动存成草稿，不会丢；
- **回看**：阅读页的「版本历史」列出每一版，任意一版都能重新拿出来。

## 几个去处

| 想做什么 | 去哪儿 |
| --- | --- |
| 看有哪些笔记 | `special:all`（全部页面） |
| 找最近改过的东西 | `special:changes`（最近编辑） |
| 找刚才看过的一页 | `special:history`（浏览历史） |
| 放图片、附件 | `special:files`（文件） |
| 删错了想捞回来 | `special:trash`（回收站） |
| 改外观与默认设置 | `special:settings`（设置） |

## 值得知道的几句

- 地址可以写得更细：`运河@history` 看历史，`运河@view-3` 看第 3 版，`运河#小节` 直接跳到某一段；
- 内部链接写 `[[另一页]]`：蓝色表示已经有这一页，红色的点一下就能建；
- 笔记可以按需加密或签名，口令不写入磁盘；
- 删除是软删：内容与历史都留着，回收站里可以还原。
