# 渲染链路验证

这是一篇用于验证渲染链路的**示例笔记**：内容由 Rust 后端用 markdown-it
编译成 HTML，前端只负责展示，不参与解析。

## 文本与行内元素

普通段落里有 **加粗**、*斜体*、~~删除线~~ 和 `行内代码`。
带协议的裸地址会被自动识别成链接，比如 https://tauri.app；
尖括号写法 <https://www.rust-lang.org/> 也支持，还有 [带文字的链接](https://www.rust-lang.org/)。
没有协议的裸域名（例如 example.com）不会被自动链接。
