## 地址栏

地址栏是唯一的入口，而且**你看到的永远是后端解析出来的结果**。写法是

```text
命名空间:名称@状态#章节
```

`命名空间:`、`@状态`、`#章节` 都可以省略，省略到什么程度取决于你要做什么：

| 写法 | 效果 |
| --- | --- |
| `示例笔记` | 读这一页的最新一版 |
| `示例笔记#链接` | 读这一页，并滚到「链接」一节 |
| `示例笔记@edit` | 进编辑器改它 |
| `示例笔记@history` | 看它的全部版本 |
| `示例笔记@view-1a2b` | 只读地看某一版（短 id 在历史页里抄） |
| `示例笔记@rollback-1a2b` | 回退到某一版（会先让你确认） |
| `示例笔记@delete` | 删除（会先让你确认） |
| `示例笔记@no-command` | 打开这一页本身，不执行它的指令 |

`@view-` 与 `@rollback-` 后面那一小串是**提交短 id**：每次提交都会生成一个，历史页里能看到。

按住 Ctrl 点链接、或者在标签页上按**中键**，都会在**新标签页**里打开。几个快捷键：
`Ctrl+T` 新建标签页、`Ctrl+W` 关掉当前标签页（关掉最后一个会自动新开一个空白页，
所以界面不会变得没有着落）、`Ctrl+Shift+T` 把刚关掉的那个标签页找回来、`Ctrl+H` 打开**浏览历史**。

标签页上右键也有「重新打开关闭的标签页」——关错了不必去翻历史。

右键菜单是本程序自己的：图片上给「看大图」「复制图片地址」「另存为」，链接上给「复制链接地址」，
标签页上给「关闭」「关闭其它」，文件行上给「复制引用」「重命名」「删除」，
输入框里给「复制」「粘贴」。其余地方不弹菜单 —— 系统那份（Reload、Back、Inspect）
在这里没有意义。

## 链接

内部链接写 `[[目标]]`，也可以写成 `[[目标|显示文字]]`，目标在前。三种颜色各表示一种状态：

- 蓝链：[[示例笔记|这一页]] —— 目标存在；
- 红链：[[还没有的页面]] —— 目标还不存在，点它会落到可以创建的位置；
- 绿链：[[zhwiki:NASA]] —— 目标在别的站上，点了用浏览器打开。

绿链的前缀是**跨站命名空间**：仓库自带 `zhwiki`（中文维基百科）与 `qw`（求闻百科），
在设置里可以改它们的站点地址，也可以删掉。

## 指令页面

把某一页的**第一行**写成 `$$COMMAND$$`，第二行写指令，这一页就变成指令页面：打开它会执行指令。
写成别的形式都不算，所以普通正文里出现这串标记是安全的。现有的两条：

| 指令 | 作用 |
| --- | --- |
| `REDIRECT: 目标页面` | 每次打开都把你带到目标页面 |
| `RANDOM_REDIRECT: 命名空间` | 每次打开随机跳到该命名空间里的一篇 |

`RANDOM_REDIRECT` 的冒号与命名空间都可以省略，省略时从主命名空间里随机。

被重定向带到某页时，标题下方会标出来源；**来源可以点**——点它去那一页的 `@no-command`，
也就是看那一页本身，而不是再被带走一次。

## 版本与草稿

每次提交都是往日志里**追加**一条，旧版本永不改写：

- `@history` 列出全部版本，可以任选两版做差异对比；
- `@view-短id` 只读地看某一版；
- `@rollback-短id` 回到某一版 —— 不是抹掉历史，而是把那一版的内容作为**新的一版**提交。

编辑器里改到一半不必管：内容会自动存成**草稿**并随输入节流落盘，刷新或重启都不会丢；
提交之后草稿清空。阅读时如果发现还有草稿，页面上会提示一下。

## 删除与回收站

`@delete` 把这一页移入回收站，回收站里可以**还原**，也可以**彻底清除**。
彻底清除不可撤销：正文连同删除记录一起消失，只留下一个「这一版被删除」的标记，
后面的版本靠它保持链的完整。

超过保留天数的条目会被自动清理（天数在设置里改）。清理与内容回收都是**后台任务**：
点了立刻返回，进度在左下角的任务栏里看。

## 命名空间

命名空间是标题的前缀，用来分堆。仓库自带两个跨站命名空间：

| 前缀 | 指向 |
| --- | --- |
| `zhwiki` | 中文维基百科 |
| `qw` | [求闻百科](https://www.qiuwenbaike.cn/) |

另外两个不能删：主命名空间（没有前缀，你正看着的这一页就在里面）与 `special:`。

有一处容易误解：命名空间的**标识与名称是分开存的**。改名只改表里一行，
磁盘上的文件一个都不用动 —— 所以给命名空间改名是安全的。

## 特殊页面

`special:` 下的页面由程序提供，不是文件：

| 地址 | 内容 |
| --- | --- |
| `special:all` | 全部页面，按前缀分组 |
| `special:random` | 随机跳到一篇 |
| `special:newtab` | 新标签页 |
| `special:settings` | 设置：外观、存储、命名空间（每一项都有锚点，如 `special:settings#accent` 能直接跳到主题色） |
| `special:trash` | 回收站 |
| `special:gc` | 数据库回收：清理无人引用的内容块与过期草稿 |
| `special:changes` | 最近更改：全仓库的提交，按时间倒序；勾选后可连**草稿**一起看 |
| `special:history` | 浏览历史：看过的页面（界面状态，可在设置里关掉，也能单独清空） |
| `special:files` | 文件：上传、浏览、管理附件（上传后笔记里写 `![名字](名字)` 就能用） |
| `special:debug` | 诊断：仓库现状、当前页的解析与渲染、界面实测 |

## 模板块

以 `::名字` 开头的块，用**缩进**划出边界：

::quote origin="马可·奥勒留"
  凡是与你无关的念头，都可以放下。

  ::quote origin="内层"
    嵌套的引用一层比一层靠内。

块内容的缩进比头行更深，就算块内；遇到不更深的行就结束，不需要结束标记。内容会用
**整个解析器**再解析一遍，所以里面能写 markdown、能写内部链接，也能再嵌模板块。

自带这些模板：

| 模板 | 作用 |
| --- | --- |
| `quote` | 等同 markdown 的 `>`，多一个可选的 `origin` 署名（渲染在右下角） |
| `code` | 像 markdown 的代码块，但能指定 `lang=`（语言）、`lines=off`（不显示行号）、`start=10`（行号从几开始）、`highlight=2-3`（强调哪几行） |
| `aside` | 右侧信息栏：`title=` 给标题，内部内容仍按 markdown 渲染 |
| `fields` | 左右两栏的属性表：每行写成 `标签 \| 值` |
| `banner` | 一条方框标题带（信息栏里那种居中的标题条），文案写在块内；`color=#0055a4` 指定底色（字色按亮度自动配，深底不会配深字） |
| `image` | 插图：`src=` 必给，另有 `align=left\|center\|right`、`width=`、`height=`（都是上限）；注释写在图片**下面**那一行（也可以用 `caption=`） |
| `css` | 把内容当 CSS 注入页面：本项目的 CSS 变量（`--accent`、`--link-blue`…）在这里直接可用。作用范围是**这一页的内容**（页头 + 正文），所以 `h1 { }` 改得到页面标题；`.note-body` 只框住正文，标题不在里面 |
| `html` | 把内容当原始 HTML 注入；**默认过滤**脚本与事件属性，要放开得显式写 `js` |

### 它们长什么样

下面每一块都是**真的在渲染**（不是示意图）：

::banner color=#3a6ea5
  内置模板演示（这一条指定了底色）

::fields
  模板 | 用途
  code | 控制行号与要强调的行
  fields | 你这会儿看到的这张表
  image | 插图，能定位置与尺寸上限

::code lang=rust lines=on start=10 highlight=2-3
  fn main() {
      let answer = 42;

      println!("{answer}");
  }

::image src=/logo.svg align=center width=120
  居中的图：注释就写在图片下面，最宽 120 像素

信息栏是**浮动**的，所以放在这一节最后，看它怎么让正文绕着走：

::aside title="信息栏（aside）"
  侧栏浮在右侧，正文绕着它排。

  里面照常按 markdown 渲染：**强调**、[[示例笔记|内部链接]]都可以。

模板可以写在 `template:` 命名空间里再按名字取用：`::盒子` 会去找 `template:盒子` 那一页，
`::css src=样式.css` 会去找 `template:样式.css`。模板里用 `{{参数名}}` 取参数、`{{body}}` 取块内容。

没登记的模板不会被丢掉，而是渲染成一个框，把名字与参数列出来 —— 写错了看得见。

## 文件

图片、文档可以直接放进仓库：到 `special:files` 上传，或者在编辑器那一行点「插入文件」——
它会收进仓库、并在光标处写好引用。

引用写的是**文件名**（不是路径）：图片 `![名字](名字)`，要对齐或限宽就用
`::image src=名字 align=right width=320`；其它文件写 `[名字](名字)`。
仓库内部把文件存成生成的标识，文件名单独记着 —— 所以中文名、重名、换台机器搬运都不会出岔子，
重复上传同一份内容也只占一份空间。

右键图片可以**另存为**：仓库里那份由后端直接拷过去；**网上的图片也能存** ——
下载在后端做（前端会被跨域拦住），字节一样不经过页面。大图查看器左上角也有这个按钮，
文件行上也有同一项。

文件可以**改名**（右键或行里的按钮）：改的只是显示名，磁盘上的那份不动，
所以改名的代价是零。要留意一点：笔记里已经写下的**旧名字不会自动跟着改**。

图片**点一下就能看大图**（再点任意处或按 Esc 关掉）。要是图片取不到，页面上会直接写
「图片不存在」，而不是留一个加载失败的方框让人猜。

有一点与标准 markdown 不同，值得记住：**缩进代码块语法已经关掉**（四空格开头不再变成
代码块）。缩进现在专用于模板块的边界，两者会互相干扰。代码块请用围栏写法（三个反引号）。
