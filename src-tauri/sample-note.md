## 文本与行内元素

普通段落里有 **加粗**、*斜体*、~~删除线~~ 和 `行内代码`。
带协议的裸地址会被自动识别成链接，比如 https://tauri.app；
尖括号写法 <https://www.rust-lang.org/> 也支持，还有 [带文字的链接](https://www.rust-lang.org/)。
没有协议的裸域名（例如 example.com）不会被自动链接。

Setext 风格标题（在文字下一行写 `===` 或 `---`）已被刻意移除，不再解析成标题。

## 内部链接

内部链接写作 `[[目标文档|显示文字]]`——顺序同 MediaWiki，**目标在前**。
显示文字可以省略，写成 `[[文档名]]`。点击后目前**不会跳转**，只会在后端
命令行打印一行；真正的跳转要等笔记有了真实来源再接：

- [[note-example|示例条目]]
- [[只有目标]]

## 代码

行内代码长这样：`cargo tauri dev`。下面是带语言的代码块，
分词由 highlight.js 负责，配色交给主题变量，所以深浅色会跟着切：

```rust
fn main() {
    let html = MARKDOWN.parse(SAMPLE).render();
    println!("{html}");
}
```
